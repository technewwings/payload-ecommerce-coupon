# Contributing to @wtree/payload-ecommerce-coupon

Thank you for your interest in contributing! This document provides guidelines and instructions.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/payload-ecommerce-coupon.git`
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature`

## Development

```bash
# Run tests
npm test

# Watch mode
npm run test:watch

# Lint code
npm run lint

# Type check
npm run type-check

# Build
npm run build
```

## Pull Request Process

1. Ensure tests pass: `npm test`
2. Update CHANGELOG.md
3. Create a descriptive PR
4. Maintainers will review and merge

## Code Style

- Follow ESLint rules (auto-fix with `npm run lint:fix`)
- Use Prettier for formatting
- Write TypeScript for all code
- Include JSDoc comments for public APIs
